## 1. 9회차 수업 구조

| 회차 | 주제 | 만들 결과물 | 주로 기르는 능력 |
|------|------|------------|----------------|
| 1 | 처음 만남 — 왜 AI인가 | 분류 노트 1쪽 + 동기 정리 | 안목·동기 |
| 2 | AI에게 시키는 법 | 프롬프트 비교 분석 | 디렉팅 |
| 3 | 글과 발표 자료 만들기 | 발표 풀세트 — 슬라이드 8~10장 + 5분 스크립트 (60분) | 제작·디렉팅·검증 |
| 4 | 전문가의 톤으로 글쓰기 | 전문가 칼럼 1편 (800~1200자) | 디렉팅·검증·완성도 |
| 5 | 이미지 시리즈 만들기 | 캐릭터 8종 표정·포즈 시리즈 | 제작·안목 |
| 6 | 음성과 영상 만들기 | 30초 광고 영상 | 제작·디렉팅·완성도 |
| 7 | PC 웹 도구 만들기 | PC에서 작동하는 웹 도구 1개 | 제작·오너십 |
| 8 | 다듬기와 가려내기 | 헛소리 보고서 + 95점 리메이크 | 검증·완성도 |
| 9 | 부모님께 발표 | 캡스톤 작품 + 부모님 발표 5~10분 | 오너십·발표력·종합 |

### 회차별 상세 (미션 생성 시 참고)

**1회차 — 처음 만남**
AI로 만든 작품 30개를 좋은 것/평범한 것/나쁜 것으로 분류하고 각 이유를 본인 언어로 설명. 왜 배우는지 자기 언어로 정리.

**2회차 — AI에게 시키는 법**
동일한 결과물을 (가) 한 줄 명령형 (나) 역할·맥락·제약 부여 (다) 예시 첨부+차이점 명시, 세 방식으로 시켜 비교 분석.

**3회차 — 글과 발표 자료**
처음 듣는 주제로 슬라이드 8~10장 + 5분 발표 스크립트 풀세트를 60분 안에 완성. 사실 오류 0건 목표.

**4회차 — 전문가 톤 글쓰기**
학생 관심 분야의 전문가 칼럼/리뷰/분석 글 800~1200자. 일반 블로그 글과 전문가 글의 차이를 먼저 분석 후 작성.

**5회차 — 이미지 시리즈**
본인 캐릭터 1개를 정하고 8가지 표정·포즈를 일관된 스타일로 제작.

**6회차 — 음성과 영상**
가상 제품 1개의 30초 광고 영상. 콘셉트 1쪽 → 소재 추출 → 영상 합성 순서.

**7회차 — PC 웹 도구**
시간표 정리, 단어장, 시험 알림, 간단한 게임 등 친구나 본인이 실제로 쓸 수 있는 것. URL로 공유 후 다음 회차에 사용 후기 1줄 받아옴.

**8회차 — 다듬기와 가려내기**
전반부: AI가 답한 5가지 사실 중 거짓 2개를 가려냄("헛소리 사냥"). 후반부: 이전 작품 중 가장 아쉬웠던 것을 골라 95점 버전으로 리메이크.

**9회차 — 부모님 발표**
9회차 동안 배운 것, 자랑하고 싶은 작품, 앞으로 만들고 싶은 것을 직접 기획해 슬라이드+작품 시연+5~10분 발표.

## 2. 기르는 6가지 능력

| 번호 | 이름 | 키워드 | 정의 |
|------|------|--------|------|
| i | 안목 | 보기 | 좋은 결과물과 평범한 결과물을 분간하는 눈. 안목이 없으면 AI 출력이 다 좋아 보인다. |
| ii | 디렉팅 | 시키기 | 모호한 요구를 명료한 지시로 바꾸는 능력. 도구가 바뀌어도 평생 가는 능력. |
| iii | 제작 | 만들기 | 도구를 부려 실제 결과물을 뽑아내는 손. 글·그림·영상·코드 가리지 않음. |
| iv | 검증 | 판단 | AI의 헛소리·평범함·뛰어남을 가려내는 비판력. AI에 의존하지 않는 핵심. |
| v | 완성도 | 다듬기 | 50점 결과물을 80점, 95점으로 끌어올리는 집요함. 시간이 아니라 다른 능력을 쓰는 일. |
| vi | 오너십 | 서명 | "이건 내 작품이다"라고 말할 부분이 결과물에 있는가. 이 책임감이 마지막을 결정한다. |

## 3. 미션 카드 양식

각 회차에 학생에게 전달하는 카드. "가상의 의뢰인이 시킨 일처럼" 구성하는 것이 핵심.

| 항목 | 설명 |
|------|------|
| **미션 종류** | 현장 (수업 중 제작) / 과제 (수업 후 제출) |
| **회차/번호** | 예: 4회차 / MISSION-04 |
| **의뢰인** | 가상의 인물·기관. 학생 관심 분야에 맞게 변형. 예: "축구 전문지 편집장", "게임 매거진 에디터" |
| **상황** | 의뢰인이 놓인 맥락 1줄. 예: "다음 주 특집호 마감이 사흘 남았습니다." |
| **최종 산출물** | 학생이 만들어야 하는 구체적 결과물. 예: "축구 칼럼 1편 (800~1200자)" |
| **제약** | 지켜야 할 조건. 예: "사실 오류 없을 것 / 전문가 톤으로 / 60분 이내" |
| **성공 기준** | 의뢰인이 납품을 수락하는 기준. 예: "편집장이 수정 없이 바로 쓸 수 있는 수준" |
| **심사관** | 발표 때 교사가 맡는 역할. 의뢰인과 동일하거나 관련 전문가. |

## 4. 디자인 톤

학부모용 안내문에서 읽히는 디자인 감각.

- **톤 키워드:** 군더더기 없음, 여백 중시, 따뜻하지만 진지함, 학원 느낌 배제
- **언어 스타일:** 짧고 선명한 문장. 수식어 최소. 핵심만. 동사를 앞세움.
- **구조:** 큰 헤딩 → 한 단락 설명 → 표 또는 목록. 위계 명확.
- **색:** 흰 배경, 거의 검정에 가까운 짙은 본문. 포인트 색: 선명하지 않은 따뜻한 오렌지 (`#D4875C`). 연한 버전 `#F0C4A8`, 짙은 버전 `#B06840`.
- **폰트:** 한국어 본문 Pretendard (sans-serif 위주). 제목·강조에 Noto Serif KR 혼용 가능.
- **여백:** 넉넉함. 콘텐츠가 숨 쉬게 함. 줄간격 넓음.
- **강조:** 볼드 활용. 형광펜·밑줄 최소화.
- **미션 카드 느낌:** "의뢰서"처럼 보여야 한다 — 공문서보다 가볍고, 게임 퀘스트보다 진지하게.

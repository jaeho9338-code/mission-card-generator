# growth-analytics — 개발 가이드

## 이 도구가 무엇인가

학부모에게 보여주는 **성장 리포트 생성기**다.

강사가 운영하는 중학생 AI 디렉팅 수업(9회차)에서,
학생이 회차별로 제출한 프롬프트를 Claude AI가 분석해
학부모가 "우리 아이가 성장했구나"를 말 없이 느낄 수 있도록
시각적으로 보여주는 도구다.

---

## 핵심 목적

> **말 없이 "우리 아이가 성장했구나"를 느낄 수 있게.**

수치와 차트가 아니라, 비포/애프터를 나란히 놓는 것만으로
부모가 자녀의 성장을 직관적으로 체감하게 한다.

---

## 화면 구조 — 탭 두 개

### 탭 1 — INPUT (데이터 입력)

- 학생 드롭다운 (기존 학생 목록 + "새 학생 추가" 인라인)
- 회차 드롭다운 (1~9)
- 메모 입력 (운영자 내부용, 선택사항)
- 프롬프트 텍스트에어리어 (크게)
- 저장 버튼
- 하단 저장 현황 테이블 (학생명 / 저장 회차 / 마지막 저장일)
- 같은 학생 + 같은 회차 재저장 시 확인 다이얼로그 후 덮어쓰기

### 탭 2 — REPORT (성장 리포트)

- 학생 선택 드롭다운
- "몇 회차까지 분석할지" 숫자 입력
- 분석 시작 버튼 → API 1회 호출 → 4개 구역 렌더링

---

## 데이터 저장 방식

- 저장 위치: `growth-analytics/data/{학생이름}.json`
- 읽기/쓰기: Next.js API Route + Node.js `fs` 모듈
- 운영자가 파일을 직접 편집할 필요 없음

```json
{
  "name": "민수",
  "sessions": [
    {
      "round": 1,
      "prompt": "프롬프트 원문",
      "note": "",
      "savedAt": "2026-05-01T10:00:00"
    }
  ]
}
```

## 10개 지표 정의

| 약어 | 한글 이름 | 한 줄 정의 |
|------|-----------|------------|
| DIR | 디렉팅 밀도 | 역할·맥락·구체적 지시가 얼마나 담겼는가 |
| CON | 제약 완성도 | 길이·톤·형식 등 제약 조건이 명시됐는가 |
| SPE | 구체성 지수 | 주제와 요구사항이 구체적으로 표현됐는가 |
| LEN | 유효 길이 | 단어 수와 정보 밀도가 충분한가 |
| CLR | 목적 명확도 | 무엇을 원하는지 한 문장으로 요약 가능한가 |
| AUD | 청중 인식 | 독자·사용자가 명시적으로 지정됐는가 |
| OUT | 출력 설계 | 형식·분량·구조까지 구체적으로 지정됐는가 |
| ORI | 독창성 신호 | 독자적 관점이나 창의적 설정이 있는가 |
| CTX | 맥락 활용도 | 배경·상황·목적이 전략적으로 활용됐는가 |
| ITR | 발전 신호 | 직전 회차 대비 구조적 발전이 있는가 (1회차는 null) |

## 느슨한 평가 기준 원칙 (반드시 준수)

이 도구의 분석은 **엄밀한 측정이 아닌, 느슨한 기준의 참고용**이다.

- 중학생 기준의 관대한 채점 적용
- 완벽하지 않아도 시도 자체에 후하게 점수 부여
- 리포트 하단에 **항상** 면책 문구 표시:
  > "이 분석은 AI의 느슨한 평가 기준에 의한 것으로, 절대적 수치가 아닌 성장 흐름의 참고용입니다."

## 기술 스택

- Next.js 15 (App Router) + TypeScript + Tailwind CSS
- `@anthropic-ai/sdk` — claude-haiku-4-5 모델, 분석 버튼 클릭 시 1회 호출
- `framer-motion` — 카운터 애니메이션, progress bar 애니메이션
- `fs` 모듈 — `data/` 폴더 읽기·쓰기 (API Route)
- API 키: `growth-analytics/.env.local`

실행: 루트 `package.json`에 `"growth": "cd growth-analytics && npm run dev -- --port 3003"` 추가
→ `npm run growth` 로 실행
